# Security and data privacy

This research code processes medical images. Keep raw and derived patient data
outside the repository and follow the license, consent, and de-identification
requirements of each dataset.

Before publishing logs or issues, remove patient identifiers, absolute storage
paths, access tokens, private repository URLs, and model registry credentials.
The supplied `.gitignore` excludes common data, weight, and output formats, but
it is not a substitute for a data-governance review.
